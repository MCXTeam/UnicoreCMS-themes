# Аврора

Тема сайта [UnicoreCMS]: фиолетово-розовая палитра, своя главная и свой компонент. Учебная —
показывает, из чего состоит слой вёрстки.

| | |
| ------ | ------ |
| Идентификатор | `aurora` |
| Сторона | Сайт |
| Контракт | `^1.0.0` |
| Подменяет | Главную `/` |
| Компоненты | `ThemeHighlight` |
| Строки | `theme.aurora.hello` |

## Что меняет

- Палитра: `--vs-primary` — фиолетовый, `--vs-second` — розовый, для тёмной схемы значения свои
- Главная заменена страницей темы: заголовок из строк темы и название сайта в компоненте
  `ThemeHighlight`
- Остальные страницы сайта остаются от ядра

## Файлы

| Файл | Что в нём |
| ------ | ------ |
| `theme.json` | Манифест: сторона, префикс компонентов, файл токенов, подмена страниц |
| `nuxt.config.ts` | Регистрация компонентов темы и подключение `tokens.scss` |
| `assets/tokens.scss` | Палитра для светлой и тёмной схемы |
| `components/Highlight.vue` | Компонент темы |
| `pages/index.vue` | Своя главная |
| `locales/ru.json`, `locales/en.json` | Строки темы |

## Установка

Скопируйте папку `aurora` в `themes/`, выберите тему на странице «Темы» в админке и пересоберите
сайт — подробности в [корневом README](../README.md#установка).

[UnicoreCMS]: https://github.com/MCXTeam/UnicoreCMS
