# Нуар

Вторая тема сайта [UnicoreCMS]: чёрно-серая палитра и две подменённые страницы. Учебная — на паре
с «Авророй» показывает, что тем может лежать сколько угодно и переключаются они без правок кода.

| | |
| ------ | ------ |
| Идентификатор | `noir` |
| Сторона | Сайт |
| Контракт | `^1.0.0` |
| Подменяет | Главную `/` и страницу доната `/donate` |
| Компоненты | `ThemeMarquee` |
| Строки | `theme.noir.hello`, `theme.noir.donate` |

## Что меняет

- Палитра: почти чёрный `--vs-primary` и серый `--vs-second`, в тёмной схеме они меняются местами
  по светлоте
- Главная и страница доната заменены страницами темы, обе с компонентом `ThemeMarquee` — строкой
  вразрядку с полосой слева
- Остальные страницы сайта остаются от ядра

## Файлы

| Файл | Что в нём |
| ------ | ------ |
| `theme.json` | Манифест: сторона, префикс компонентов, файл токенов, подмена двух страниц |
| `nuxt.config.ts` | Регистрация компонентов темы и подключение `tokens.scss` |
| `assets/tokens.scss` | Палитра для светлой и тёмной схемы |
| `components/Marquee.vue` | Компонент темы |
| `pages/index.vue`, `pages/donate.vue` | Свои страницы вместо страниц ядра |
| `locales/ru.json`, `locales/en.json` | Строки темы |

## Установка

Скопируйте папку `noir` в `themes/`, выберите тему на странице «Темы» в админке и пересоберите
сайт — подробности в [корневом README](../README.md#установка).

[UnicoreCMS]: https://github.com/MCXTeam/UnicoreCMS
