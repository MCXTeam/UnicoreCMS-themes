# Графит

Тема панели управления [UnicoreCMS]: серый preset PrimeVue, скруглениями поменьше и свой дашборд.
Учебная — показывает, чем тема панели отличается от темы сайта.

| | |
| ------ | ------ |
| Идентификатор | `graphite` |
| Сторона | Панель |
| Контракт | `^1.3.0` |
| Подменяет | Дашборд `/` |
| Компоненты | `ThemePanel` |
| Строки | `theme.graphite.hello`, `theme.graphite.text` |

## Что меняет

- Preset PrimeVue — `lara` вместо стандартного, палитра `primary` переведена в серый, радиусы
  уменьшены до 2, 4 и 6 пикселей. Всё это задаётся в манифесте полями `primevue` и `primevueTokens`
- `assets/tokens.scss` доводит вёрстку панели: те же скругления у сайдбара и карточек, шапка без тени
- Дашборд заменён страницей темы: карточка `ThemePanel` и слот `dashboard` для модулей

## Палитра задаётся в манифесте

Переменные `--p-*` в CSS переопределять бесполезно: PrimeVue вставляет их скриптом позже любого
файла стилей. Поэтому цвета и радиусы живут в `primevueTokens` — это те же токены, что принимает
`definePreset`, а в `tokens.scss` остаётся только собственная вёрстка темы.

## Слоты модулей остаются на подменённой странице

Дашборд темы выводит `<ExtensionSlot name="dashboard" />`. Уберёте его — вставки модулей на
дашборде пропадут, потому что рисовать их больше некому.

## Файлы

| Файл | Что в нём |
| ------ | ------ |
| `theme.json` | Манифест: сторона `admin`, preset и токены PrimeVue, подмена дашборда |
| `nuxt.config.ts` | Регистрация компонентов темы и подключение `tokens.scss` |
| `assets/tokens.scss` | Своя вёрстка панели |
| `components/Panel.vue` | Компонент темы |
| `pages/index.vue` | Свой дашборд |
| `locales/ru.json`, `locales/en.json` | Строки темы |

## Установка

Скопируйте папку `graphite` в `themes/`, выберите тему на странице «Темы» в админке и пересоберите
панель — подробности в [корневом README](../README.md#установка).
